사용법

마우스

  • 파란 줄을 누르면 그 링크로 갑니다
  • 문단 안의 링크는 마우스를 올리면 줄이 밝아집니다. 링크 글자를 누르세요
  • 위 툴바: 뒤로, 앞으로, 다시 받기, 시작 페이지
  • 주소창을 누르면 주소를 입력합니다 (https:// 는 안 써도 됩니다)
  • 아래 오른쪽 화살표: 한 화면씩 위아래로
  • 오른쪽 스크롤 막대: 끌어서 움직입니다
  • ▶ 로 시작하는 줄을 누르면 펼쳐지고, ▼ 를 누르면 접힙니다
  • 레이아웃 모드(실제 사이트 모양)에서는 스크롤 대신 ↑↓ 나 아래 화살표로 쪽을 넘깁니다. 실험 기능이라 글이 겹치거나 어긋날 수 있습니다

양식

  • 회색 칸을 누르면 입력창이 뜹니다. 검색창은 Enter 로 바로 보냅니다
  • □ 와 ○ 를 누르면 켜고 끕니다. ▾ 는 누를 때마다 다음 선택지로
  • 슬라이더는 동그라미를 누른 채 끕니다
  • [ 단추 ] 를 누르면 보냅니다. 로그인처럼 POST 로 보내는 양식은 지원하지 않습니다

키보드

  • 위/아래, PageUp/PageDown, Space, Home/End : 스크롤
  • Backspace : 뒤로
  • g : 주소 입력 · r : 다시 받기 · h : 시작 페이지

웹 페이지를 열 때

  • 왼쪽 띠에 색 격자가 뜨고 아래에 입력창이 열립니다
  • 중계 앱이 격자를 읽고 응답을 클립보드에 넣습니다
  • 입력창에 Ctrl+V, 그리고 Enter
  • 그만두려면 빈 칸으로 Enter

안 될 때

  • 무대 왼쪽이 다른 창에 가려지지 않았는지 봅니다
  • 브라우저 확대를 100% 로, 다크 모드나 색 필터는 끕니다
  • 무대가 너무 작으면 못 읽습니다. 창을 키웁니다
  • 화면이 멈춘 것 같으면 ESC 를 누릅니다
  • 글자가 넘치거나 링크를 누르는 자리가 어긋나면 글자 폭 확인 페이지를 봅니다
