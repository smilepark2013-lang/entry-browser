# 엔트리 작품 설명 (붙여 넣기용)

엔트리 작품 페이지의 **작품 설명**에 아래 글을 붙여 넣습니다. (이 파일은 소개 페이지에 쓰이지 않습니다)

---

[실험용 작품입니다]

엔트리 블록으로 만든 텍스트 브라우저입니다. 엔트리 작품은 인터넷에 닿을 수 없어서, 내 컴퓨터에서 도는 **중계 앱**이 화면과 클립보드로 실제 웹을 이어 줍니다.

중계 앱 받기 · 사용법 · 소스:
https://smilepark2013-lang.github.io/entry-browser/

쓰는 법
1. 중계 앱을 켜고, 이 작품이 열린 브라우저 창을 고른 뒤 [캡처 시작]
2. 작품에서 파란 링크나 주소창을 누르면 왼쪽에 색 격자와 입력창이 뜹니다
3. 알림이 뜨면 입력창에 Ctrl+V → Enter

꼭 읽어 주세요
- 중계 앱은 고른 창을 캡처하고(저장하지 않음) 클립보드를 덮어씁니다.
- 작품이 요청한 주소를 내 컴퓨터에서 가져옵니다. 내부망 차단 같은 보호 장치가 있지만 완벽하지 않습니다.
- 가상 머신이나 Windows Sandbox 같은 격리된 환경에서, 믿을 수 있는 작품과만 쓰세요.
- 엔트리·네이버 커넥트재단과 관련 없는 개인 실험 프로젝트입니다. (MIT 라이선스)
